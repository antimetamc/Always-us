# Always Us ❤️

Always Us is a private mobile-first PWA created for Nico and Gio.

## Features

- ❤️ Real-time relationship timer
- 💌 Missing-you messages
- 📖 Memories
- 💕 Personal messages
- ⏳ Next meeting countdown
- ⚙️ Custom settings
- 📱 Installable PWA
- 💾 LocalStorage persistence
- 🌙 Offline support

## Privacy

Version 1 does not use:

- Accounts
- Backend
- Location tracking
- Tracking
- Ads
- Public profiles

All personal data is stored locally in the browser using LocalStorage.

## Technologies

- HTML
- CSS
- JavaScript
- PWA
- Service Worker
- LocalStorage
